📝 Babble

基于 Cloudflare Workers 的极简说说服务 —— memos 复刻，API + CLI 优先，全托管零运维

🚀 快速开始 GitHub

安装与使用（CLI）

单文件零依赖脚本（仅需 curl + jq），日常发说说就是一条命令。

1️⃣ 安装（一条命令）

# Windows：从 GitHub Releases 下载 babble_*_windows_amd64.exe
#         重命名为 babble.exe 放入 PATH 即可（零依赖单文件）
# macOS / Linux：
curl -fsSL https://bb.kyeo.top/cli -o babble && sh babble --install

Go 单文件版（Windows/macOS/Linux）见 Releases；脚本由你的 Babble 服务器直出（jsDelivr 回源），国内可达。

2️⃣ 登录（一次性）

babble login <用户名> <密码>    # 签发长期 API token，存 ~/.config/babble/

3️⃣ 随手发布

babble "今天天气不错"            # 快速发布说说
echo "管道内容" | babble post    # stdin 发布
babble list / search / show / edit / pin / archive / delete / upload

不用 CLI？直接调 REST API 或用手机快捷指令（HTTP POST）即可，见 使用文档。

自己部署（约 5 分钟）

  1. Fork 本仓库；
  2. 配置 Cloudflare API Token 等少量 Secrets；
  3. Actions → Deploy to Cloudflare Workers → Run workflow。

详细步骤见 部署文档。D1 + R2 + KV 免费额度足够个人使用。
