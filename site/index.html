📝 Babble

基于 Cloudflare Workers 的极简笔记服务 —— memos 复刻，自托管，跨端同步

⬇️ 下载 Android APP GitHub

功能特性

✍️ Markdown 笔记

列表 / 编辑 / 标签 / 置顶 / 归档，分页加载与下拉刷新。

📎 图片与附件

R2 存储，图片直出，随 memo 级联清理。

🔗 公开分享

一键生成分享短链，无鉴权访问，随时撤销。

⚡ 实时推送

WebSocket / SSE 双通道，断线增量补偿。

🔐 自主账号

服务器地址可配置，用户名 / 密码随时自助修改。

📦 一键部署

fork + 3 个 Secret，GitHub Actions 自动部署到 Cloudflare。

下载与更新

Android APP 支持 自动更新：启动时检查 / 设置页手动检查，检测到新版本自动下载、校验并安装。
